Privacy policy

Last updated: 3 November 2026

SurvivorsForge has three parts: the launcher (the desktop app, also in the Microsoft Store), the platform with its website forge.rezondes.net and its API forgeapi.rezondes.net, and this homepage. This page says which personal data each part processes, why, and for how long. SurvivorsForge shows no ads, uses no tracking or analytics services and sells no data.

Who is responsible

Rezondes
Email: dev@rezondes.net

Questions about this policy can also go to the issue tracker; anything private, please by email.

The launcher

On your computer

Settings, the install state of your addons and a cache of the addon list and its images stay on your computer, in %APPDATA%\SurvivorsForge (Linux: ~/.config/SurvivorsForge; the Microsoft Store version keeps them in its own app folder). They are not sent anywhere. Uninstalling the Store version removes them; otherwise delete the folder.

Talking to the platform

The launcher loads the addon list, release details, icons and screenshots from the platform API. Like every server, the API sees your IP address with each request. It uses the address only in memory, to limit how many requests one sender can make, and does not write it to its database or logs.

Anonymous statistics

After each install or update of an addon from the platform, the launcher sends one event: whether it was an install or an update, whether it failed and with which fixed error code, the addon and its version, the launcher version and the operating system (Windows or Linux). No file paths, names or error texts are sent.

With the events comes a random installation ID, made on the first start. It contains nothing about you or your computer and is sent only to the platform, never to GitHub. It lets us count active launchers and find the requests of one installation when something goes wrong. Events without the ID are told apart for one day by a hash of the IP address with a key that changes every day and is never stored; these hashes are deleted after two days.

You can turn off the events, or only the installation ID, in the launcher under Settings, Statistics. The events are kept for the statistics without a time limit; they contain no IP address. Totals are public on the website's statistics page.

Legal basis: our legitimate interest in knowing which addons are used and in finding errors (Art. 6(1)(f) GDPR). You can object at any time by turning the statistics off.

Downloads from GitHub

Addon files and launcher updates come straight from GitHub (github.com, codeload.github.com and GitHub's download hosts). When the platform cannot be reached, the launcher also reads release pages on github.com itself. GitHub then sees your IP address; see the GitHub privacy statement.

Microsoft Store

If you install SurvivorsForge from the Microsoft Store, Microsoft processes the data of the purchase, installation and updates under the Microsoft privacy statement. We only receive Microsoft's aggregated reports, such as the number of installs.

The website

Browsing

You can browse addons without an account. Every visitor gets one cookie, forge_csrf, a random value that protects forms against forgery; it says nothing about you. Avatars and images in addon descriptions load from GitHub's servers, which then see your IP address. Downloads of addon packs are counted with the same daily hash as above.

Logging in with GitHub

To publish addons, write comments or report problems you log in with your GitHub account. We then store your GitHub user ID, your GitHub username, the address of your avatar, your role, and when you joined and last logged in. Sessions are stored only as a hash of their token.

The website uses only cookies it needs to work, all encrypted and not readable by scripts: forge_session (your login), forge_csrf (see above), forge_login (only during a login) and forge_github. The last one holds the token GitHub hands over at login, so the website can post issue reports and replies on GitHub in your name. It stays in your browser; the platform does not store it. Logging out removes the cookies.

What you write

Comments, addon pages and reports to the admins are stored on the platform and shown with your GitHub username. Bug reports and replies to them are posted to the addon's GitHub repository under your GitHub account and are then subject to GitHub's terms. You can edit or delete your comments; a deleted comment is no longer shown. To have its text removed from the database as well, write to the address above.

Legal basis: providing the service you asked for (Art. 6(1)(b) GDPR), and our legitimate interest in keeping the platform safe, for example in moderation (Art. 6(1)(f) GDPR). Your account data is kept while you use the platform. To have your account deleted, write to the address above.

This homepage

This homepage is hosted by GitHub Pages and sets no cookies. GitHub logs the IP address of each visit to run the service. To show the current version, the page asks api.github.com for the latest release from your browser.

Your rights

Under the GDPR you have the right to access your data, to have it corrected or deleted, to restrict its processing, to receive it in a portable format, and to object to processing based on our legitimate interest. Write to the address above. You also have the right to complain to a data protection supervisory authority.

Changes

When SurvivorsForge starts to process data differently, this page changes first. The date at the top shows the last change.
