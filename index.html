What it does

One place for every addon you play with, made for this one game.

Install in one click

Pick an addon in Browse and it lands in the right folder, with the folders it needs. No unpacking by hand.

Updates for all of them

One check finds new versions of every addon you have, and Update all installs them at once.

Dependencies included

Addons that need a library get it installed with them, in the right order. Optional extras are named before you install.

Your own sources

Add any addon from a GitHub repo or install a zip from your disk. Addons already in your folder are found and tracked.

Fits your game version

Set your game version once and you are told before installing an addon that does not support it.

Safe removal

Removed addons go to the recycle bin. Your addon settings in the WTF folder stay untouched.

Steam Deck ready

Runs as an AppImage on Linux and SteamOS, with large touch controls in Game Mode.

Works offline

Without a connection you still see your addons and the last known list. Nothing is installed until the check is possible again.

Updates itself

A new version of SurvivorsForge shows up as a banner and installs with one click.

Checked before it reaches you

Addons run inside your game. So every release is looked at before anyone installs it, and the launcher makes sure you get exactly the file that was looked at.

  1. Scanned

    Each new release is opened by an isolated worker, and its Lua and XML are checked for code that has no place in an addon.

  2. Reviewed

    Anything the scan finds goes to the admins. They verify a version by hand or block it.

  3. Fingerprinted

    The platform keeps the SHA-256 of every checked file. The launcher compares it after each download and refuses a different file.

  4. Watched

    Files on GitHub are checked again regularly. A release that changes afterwards loses its badge until it is checked again.

Playing in the browser?

The browser version of the game takes addons as a zip upload. An addon pack puts all the addons you want into one zip, ready to upload.

  • Tick the addons on the website or in the launcher
  • Download one zip, every addon in its own folder
  • Share the link: your friends see what is inside and get the same zip

For addon authors

Your code stays in your GitHub repo. The platform reads your releases and brings them to the players.

Publish from GitHub

Log in with GitHub, install the SurvivorsForge App on your repo and your addon is listed. Every new release appears on its own.

Your page

Description in Markdown, screenshots, an icon, the category and the game versions each release supports.

Work as a team

Add contributors who may edit the description or the images, and name the libraries your addon needs.
