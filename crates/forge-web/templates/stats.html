What is counted and what is not

  • No cookies and no tracking script.
  • No IP addresses stored.
  • The launcher's installation ID is forgotten after 90 days.
  • Search words without a result are deleted after 90 days.

Launcher

After each install or update of a verified addon, the launcher sends one anonymous event: whether it was an install, an update or a rollback to an older version, the addon and its version, the launcher version and the operating system. When it fails, a fixed code such as hash_mismatch goes along, never an error text, a path or a name.

Each launcher also has a random installation ID. It says nothing about you or your computer and helps to find out what went wrong when something fails. It goes only to this platform, never to GitHub, and is forgotten after 90 days; the counts stay. With it the platform counts how many launchers of each version and operating system were active in an hour and in a day.

Website

The website counts page views the same way: which page, the site a visitor came from, the country Cloudflare reports and whether it is a phone, a computer or a Steam Deck. It sets no cookie and runs no tracking script. A search of the addon list that finds nothing is counted with its words (at most four, no e-mail addresses) to see which addons people miss; these are deleted after 90 days.

No IP address is stored. To count each visitor once a day, the address is turned into a code with a key that changes every day and is never written down.

In the launcher, Settings > Statistics turns the events off, or only the installation ID.
