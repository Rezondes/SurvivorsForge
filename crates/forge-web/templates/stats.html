What the launcher sends

After each install or update of a verified addon, the launcher sends one anonymous event: whether it was an install or an update, the addon and its version, the launcher version and the operating system. When it fails, a fixed code such as hash_mismatch goes along, never an error text, a path or a name.

Each launcher also has a random installation ID. It says nothing about you or your computer and helps to find out what went wrong when something fails. It goes only to this platform, never to GitHub, and is forgotten after 90 days; the counts stay.

No IP address is stored. To count each visitor once a day, the address is turned into a code with a key that changes every day and is never written down.

In the launcher, Settings, Statistics turns the events off, or only the installation ID.
